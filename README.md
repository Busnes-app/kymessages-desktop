# KyMessages Desktop

Desktop client for [KyMessages](https://github.com/Busnes-app/KyMessages-Native) on Windows, macOS, and Linux, providing encrypted chat, voice and video calls, and screen sharing as part of the [busnes.app](https://busnes.app) suite.

## Status

This repository is an early placeholder. The desktop client implementation has not yet been published here.

In the meantime, KyMessages is available via the web client bundled with the [KyMessages server (`KyMessages-Native`)](https://github.com/Busnes-app/KyMessages-Native).
